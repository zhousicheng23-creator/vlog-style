# 短暗场与明暗过渡

用于需要停顿、收束或改变节奏的场景连接，是直接切、声音衔接、动作引导蒙版等方法之外的可选做法。不默认每次切镜都加黑，也不固定黑场长度、淡化曲线或调色参数。

## 适用情境与选择

| 情境 | 作用与判断 |
| --- | --- |
| 快切进入正文 | 让速览告一段落，再进入当天内容；直接切已清楚时不必再加黑或第二个片头 |
| 动到静 | 从篮球、训练等运动段转入看书或生活，让声音与画面共同放缓 |
| 一项活动结束 | 动作和结果已经交代清楚后收束，不用变暗遮掉关键结果 |
| 真实时间变化 | 提示确实发生的时段或场景变化；黑场不证明过了多久，不编造时间跨度 |
| 幽默停顿 | 接住真实反应、小意外或自嘲；保留理解笑点需要的表情，不靠黑屏编剧情 |
| 真实遮黑 | 手、衣服、物体或暗处实际遮住镜头时利用遮挡连接，先核对是否足以覆盖画面 |

先实际查看 A、B 两段，判断动作、场景关系、明暗变化和原声。只做方案且没有素材时，注明假设，不声称已经确认入点或效果。

## 三种做法

### 利落短闪黑

用短暂纯黑形成明确的切分，适合快切收束或有意停顿。按前后镜头节奏决定是否直接切黑，或在两侧加很短的淡出、淡入。黑段应让观众感到有意设计，避免短到像掉帧，或长到误以为播放结束；不套固定帧数。

### 柔和淡黑

让 A 尾部逐渐变暗，再让 B 从暗处进入，适合动到静、活动结束或真实时段转换。可以没有额外纯黑段，也可以停留片刻；分别判断两侧淡化时长，不要求对称。逐帧检查关键动作是否仍看得清，正常速度判断是否拖沓。

### 真实遮黑

利用素材已有的全屏或接近全屏遮挡，在遮挡最充分处连接下一幕。确认实际遮挡范围、运动方向与前后亮度，避免伪装成真实遮黑却提前露底。

若需要沿书页、人物、门或手的边缘逐步揭示下一幕，改读[动作引导蒙版转场](motion-mask-transitions.md)。本参考不提供边缘跟踪，也不把普通亮度淡化描述成蒙版转场。

## 剪辑与时间线

1. **先定动作，再定变暗。** 让观众看清本次要交代的动作与结果后再变暗，不能用淡出盖住进球、接触或关键反应。用户明确要求在出手等节点切走时，遵守指定节点，不擅自补结果。
2. **收紧 A 的无效尾部。** 去掉无意义的等待与准备，保留理解结果所需的表情、自然收尾和必要停稳；既不机械拖长，也不切得像动作未完成。
3. **选 B 的有效入点。** 从能辨认场景、人物或有效动作的位置进入，避免黑场后仍在等动作。淡入覆盖的部分也在播放，不让需要看清的首个动作被黑暗吞掉。
4. **明确淡化占用区间。** 淡出叠在 A 的尾部，淡入叠在 B 的头部；它们通常不额外增加片长。不要把淡化时长再次当作空白插入。
5. **单独计算纯黑。** 若额外插入纯黑，后续时间线同步后移：B 及之后的画面、对应原声、字幕、音乐关键点和效果都更新。避免只延后画面导致声音或字幕提前。前声延续、后声提前或贯穿音乐属于有意设计，另行记录其跨越区间；贯穿 BGM 不必整轨机械后移，应重算衔接点和尾长。
6. **按帧落地。** 先确定输出帧率，将边界和时长取整到帧，记录舍入方式及实际帧数；以累计帧边界计算时码，避免逐段秒数舍入后累积误差。检查无意的缝隙、重复帧和 B 入点重播。
7. **保留记录。** 记录 A/B 源区间、速度、输出起止帧、淡出/淡入区间、纯黑帧数、声音跨越方式、后续偏移及输出规格。纯黑之外若存在自然暗画面，分别标明，便于复现和验收。

只有 A、额外纯黑、B 顺次拼接时，总时长为 `A 保留时长 + 纯黑时长 + B 保留时长`；叠在镜头内部的淡化不另加时长。若另做重叠、变速或其他结构，按实际时间线重新计算。

## 声音选择

- **前声延续：** 让 A 的自然尾声跨过暗场，带到 B；适合篮网、房间环境等仍有连贯感的声音。只保留实际录到的声音，不通过复制拉长或另造声音冒充现场。
- **后声提前：** 先听到 B 的环境或完整语句，再看到 B。明确提前量，避免提前带入尚未发生的可见接触声。
- **短静：** 黑场可以短暂安静，也可以保持底噪；依据叙事选择，处理边界爆点，避免将短静误做成音轨缺失。
- **音乐退出或贯穿：** 动到静时可让音乐自然渐弱，也可一首贯穿。淡出时机按动作、原声和本期要求决定，不默认切黑就停歌，也不默认加快门声或短重鼓。
- 画面与对应原声共用源区间及变速映射。碰球、入网、翻页、合盖等明确动作的接触声对准实际发生时刻，不为填满黑场把接触声挪动；自然尾声可按设计延续。
- 保留口播词句与语意完整，淡化和黑场不作为切断句子的借口。音乐让位于说话及必要现场声，避免音量突跳。
- 原录音中混有音乐或杂声时如实说明，不称为已分离的纯现场音效；不得编造未发生的现场声。

## 亮度与附加效果

- 先让两侧曝光、肤色与主体细节自然，再决定变暗曲线。运动段可偏暗，但不能靠抬高 gamma 或亮度硬救所有镜头，也不能压黑关键动作。
- B 的淡入与原片暗部共同决定可见程度，检查主体何时真正清楚；避免黑场刚结束又像持续黑屏，或进入时突然过曝。
- 缩放、轻微抖动及其他强调只在有助于动作或停顿时使用，幅度和时机依素材判断。不将案例中的 gamma、推近、抖动或淡化时长当作默认模板。

## 执行边界与验收

本文件提供剪辑判断与记录规则，未新增自动剪辑工具。实际执行使用当前项目可用工具并遵守项目约定；调用 video-use 时先读其技能，上游 helper 使用 `python video_use.py <helper> ...`，不假定全局 FFmpeg 可用。

- 用户只要方案时只输出方案，不修改素材、工程或视频；用户已授权局部预览或整片时按该范围执行，不因本参考额外要求逐步确认。
- 新效果通常先检查带前后场景的局部预览；已有整片执行授权时可继续应用。保护全部原始照片、视频和录音，不覆盖或删除原片；本项目工作输出放 `edit/`，交付放 `outputs/`。
- **正常速度观看并试听：** 动作结果清楚，停顿有作用，B 入点有效，动静关系自然，口播完整，音乐与原声没有突兀跳变。
- **逐帧检查：** 淡化起止、纯黑帧数、源区间接续、接触动作与声音对应正确，关键动作未被提前压黑，后续字幕和效果未因插黑错位。
- **区分有意黑场与故障黑闪：** 有意暗场有记录的起止帧和叙事作用；计划外的单帧黑、缺帧、解码异常或拼接空隙应排查。黑帧检测只是定位线索，不能把所有暗画面一律删掉或一律视为设计。
- 核对输出帧率、总时长、方向及可播放性；如实报告看过、听过及逐帧检查的范围，不把抽帧或波形检查说成完整观看、试听。
