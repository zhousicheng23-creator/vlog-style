# 可选案例

以下用于帮助理解风格，不是每期默认模板。使用前确认本期素材、情绪和用户要求是否适合。

## 动静对比的声音连接

开头快切配音乐
→ 切到看书时短淡出，保留翻页及环境声
→ 配重插销的真实接触声
→ 音乐短渐入
→ 第一记明显重拍对齐首次发力。

淡出长度、安静段长度和音乐入口按素材调整。不为套用这个案例而增加缺失的镜头或声音。

## 学习与运动的反差

已使用过的表达：

“代码写崩了” → “但肩不会崩”。

只适用于对应内容，不因账号是研究生就每期安排破防。普通结束工作、心情不错或单纯想运动，也能成为出发原因。

## 开头大标题

可采用三层层级：

- 最大：本期主题或情绪。
- 次级：与本期有关的身份、运动项目等信息。
- 装饰层：可选VLOG字样。

“不爱学习”“自律”等表述属于具体文案选择，不作为创作者永久人设。不能将某期标题直接当成后续每期片头。

## 字幕和转场的变化

- 场景变化：简短阶段提示，左上角为可选位置。
- 搞笑片段：少量彩色错落文字或合适的配音。
- 拍照到照片：圈选、放大或其他能说明关系的效果。
- 场景推进：有缓动的向左拉屏。
- 真实遮挡充分时：利用衣服、门框、手掌或人物经过转场。

不因案例里出现某种效果，就自动为当期增加该效果。特定歌曲版本、彩色歌词、熊二或其他配音仅在本期提出且适合时使用。

需要制作动作引导蒙版时，按[蒙版制作与音画同步](motion-mask-transitions.md)执行；[翻页至配重 V6](page-reveal-v6.md)是已认可的近似揭示案例，不限制后续只能使用书页或固定斜向运动。

需要用短暗场区分段落或改变节奏时，按[短暗场的用法、裁切与声音](dark-scene-transitions.md)选择利落闪黑、柔和淡黑或真实遮黑。其中记录“篮球入网接看书”的 V4 小样与后来讨论的整片配乐方案，不能将二者混为已完成效果，也不把约 0.2 秒黑场当成所有素材的固定参数。

## 封面方向

- 运动为主：清楚的本人动作主图，配少量主题文字。
- 日常为主：自然人物主图，加一两张有故事关系的小图。
- 多场景共同构成主题时：可以尝试三格。

排版略有错落，同时保证手机缩略图下能认出本人、读清主题。不固定每期的文案、字号、照片数量或排列方式。
