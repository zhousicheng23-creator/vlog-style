# 研究生运动日常 Vlog

## 创作者与风格

创作者是北理工AI方向男研究生，北京人，身高181cm，有健身基础，也打篮球。使用尼康Z30和苹果手机拍摄。

核心风格：**有运动感、有人味的研究生日常。**

健身和篮球体现力量、速度与身体状态；学习和生活自然松弛，保留真实反应、随口表达、小意外和轻微自嘲。让观众看懂当天发生了什么，也逐渐记住创作者本人。

不强制每期破防、励志或展示自律，不刻意强化北京口音。身份和身高是可用信息，不必每条全部展示。其他年龄、体重、训练成绩和具体经历以用户确认的信息为准。

## 使用原则

- 本期明确要求优先于风格默认；具体案例只在适合本期时采用。
- 当期修改默认只影响当期；明确成为长期偏好后再更新本skill。
- 不预设每期时长、固定活动顺序、歌曲、转场或镜头次数。
- 不编造经历、情绪、成绩、时间、台词和运动结果。
- 需要具体做法时，阅读[可选案例](references/examples.md)，不必在每次任务中加载案例。

## 任务边界

先根据用户请求区分工作方式：

- **方案建议**：输出可操作方案，不修改素材、工程或导出文件。
- **成片评审**：查看用户指定版本，按时间码指出问题和修改建议；不将评审自动升级为实际修改。没有获得成片时，只能根据描述提出建议，不能声称已经看过。
- **实际剪辑**：在已有明确授权范围内执行，不反复确认已确定的事项。

信息不足时，只询问影响关键决策的内容；能独立推进的部分继续处理，并说明假设。

保护所有原始照片、视频和录音。日常清理仅处理确认属于生成物的缓存、中间文件和旧导出；来源不明时保留，删除原片需要用户明确指定。未经针对具体服务与素材的明确授权，不上传素材或使用付费转写。

实际操作遵守项目的AGENTS.md和可用工具的执行规范。本skill负责内容与审美，不预设某种软件一定可用；有合适的执行技能（如video-use）时配合使用。

## 故事与节奏

- 每期选择一个主要看点，其他内容帮助交代当天生活；健身、篮球、学习、吃饭不必全部出现。
- 以真实发生的顺序和关系组织内容，保证场景变化看得懂。速览或回切需要让观众分辨，不伪造事件因果。
- 开头可以用精彩片段速览，也可以直接进入有吸引力的现场。
- 快切需要辨认得出内容；动作、环境和口播需要时可以停留。运动与生活段允许有明显的动静区别。
- 快切后自然进入正文，不默认增加第二个片头或黑屏。
- 根据内容完整度和重复程度决定长度，不为凑时长增加支线。
- 结尾可以是口播、真实反应或当天最后一个动作，不强制总结升华。
- 文案像本人随口表达，避免口号和模板句。不把某一种结构或时长描述成流量保证。

## 健身与篮球

实际选定片段或执行剪辑前先查看素材，不按文件名或拍摄顺序机械拼接。仅需方案且尚未提供素材时，可以根据描述规划，并注明假设。

健身：

- 优先选状态自然、发力清楚、构图有效的片段，收紧无意义的等待、张望和准备。
- 多机位可以穿插全景、中景和特写，不要求每个动作都套同一顺序。
- 注意动作阶段、身体位置与方向，避免同一次发力剪成像做了两遍。
- 上片、插销、握杆、调座椅可以作为动作和声音连接点，保留利落且有作用的部分。
- 每个镜头保留几次动作，按本期明确要求执行，不统一套成“一镜一次”。

篮球：

- 通常交代清楚动作和结果，收紧无意义的等待。
- 明确要求在出手、离手等节点切走时，按指定节点执行，不强补空中过程或结果。
- 不同时间拍摄的篮筐特写可以作为独立蒙太奇，不伪装成同一次投篮的连续机位。
- 除了进球，也可以保留跑动、失误和真实反应。
- 分屏、加速和慢动作按素材条件选择，不默认使用；效果不遮挡动作和球的关键轨迹。

## 生活、口播与照片

- 保留本人原话和原声，收紧重复、停顿时保持语意完整，不切断词句。
- 先做必要且自然的降噪和音量整理；听不清的内容核对或标注待确认，不猜字幕、不编台词。
- 学习、吃饭、走路等片段要有必要的上下文，避免只剩下含义不明的孤立动作。
- 自然反应和小意外有助于表现性格，不为制造笑点编剧情。
- 照片可以轻微推近、小窗展示或用于对比，大小与停留时间保证看得清，不遮挡重要主体。
- 只有饭菜照片时，不伪造吃饭动作或现场反应。

## 音乐、原声与转场

- 音乐随内容起伏，可以一首贯穿，也可以自然换曲。
- 运动段有力度，生活段允许松弛，安静场景可以没有BGM。
- 口播优先，音乐适当让位；统一各段人声和原声的听感，避免爆音及无意的音量跳变。
- 通常平顺衔接；为了安静、笑点或动作强调，可以有意识地收掉音乐，用现场声承接。
- 动作可对齐鼓点或实际接触声，不要求每次切镜都卡点。
- 优先直接切、动作衔接、真实遮挡及声音提前或延后。
- 合适时使用有缓动的向左拉屏，新画面同步进入；普通叠化谨慎使用。
- 音效少量使用，不给每个切点都加“嗖”声。
- 未成功分离的现场声，不描述成纯净的单一音效。
- 特定歌曲、配音、歌词和搞笑效果按本期要求与可用来源决定；发布用途考虑实际使用许可，不默认可任意使用。

### 何时选择转场

- 动作引导蒙版：真实翻页、合电脑、推门或人物经过能连接前后场景时考虑；边缘或遮挡不足时，动作匹配、镜头运动衔接或直接切可能更自然。不把近似擦除称为真实遮挡。
- 缓动左滑：适合需要明确推进的较大场景变化；不要求所有换场都使用，也不固定方向和时长。
- 短暗场：适合活动收束、动静变化或有意停顿。选择短闪黑、柔和淡黑或真实遮黑；先让关键动作、表情或指定切点被看懂，不默认每次快切后加黑或第二片头。
- 黑画面不等于静音。按叙事选择前声延续、后声提前、短静或音乐衔接，保留真实接触声与完整口播；不默认加快门声和重鼓。

本skill决定转场意图与审美。意图已确定且需要实际制作时，按需使用可用的 `$video-transitions` 并读取对应模式参考；整片生产继续使用项目已有运行时。未安装技术技能时使用现有工具，不声称已调用未提供的技能。源码目标：[video-transitions](https://github.com/zhousicheng23-creator/vlog-style/tree/main/skills/video-transitions)。

## 字幕与封面

普通字幕：

- 简洁白色中文无衬线字体，细黑边或轻阴影，按短句断行。
- 对齐实际说话，避开脸、手、器械、球及平台界面；按本期目标画幅和平台预览检查位置。

标题和阶段提示：

- 偏运动杂志感：直立粗体、层级清楚、少量错落。
- 少量颜色用于强调，不堆厚描边、白色虚边、夸张立体字、机械标签和花哨贴纸。
- 左上角可用于阶段提示，不统一规定所有文字的位置。
- 未知时间不编造；进度条、系列编号和VLOG字样均为可选。

封面：

- 从真实素材中选择本人自然、脸或动作清楚的画面。
- 可用单张主图、主图加小图或三格，根据本期内容选择。
- 少字，突出本期看点，不把全天活动全部写上；手机缩略图下仍能认出主体、读清主题。
- 已明确不喜欢的姿势和表情不再选。
- “北理工”和“北京985”等身份信息按需要选择，避免重复堆叠。
- 封面承诺的内容应在视频里得到体现。

## 画面与交付

- 默认导出9:16、1080×1920、30fps；本期指定其他规格时按要求，仅变更指定项，其余沿用适用的默认值。
- 保留原始4K等素材，不把导出规格当成拍摄限制。
- 30fps素材以原速为主，慢放前检查实际流畅度，不默认使用补帧制造动作细节。
- 混合横竖素材时保证人物正向、不拉伸，裁切保留重要信息；裁切无法兼顾时调整布局或说明限制。
- 先统一机位之间的亮度和肤色，再做氛围调整，逐段判断，不整条套同一固定参数。
- 训练画面可以偏暗，但脸、肌肉、手和器械仍要有细节。
- 美颜和镜像逐段判断，保留真实长相、体形和环境方向，注意衣服文字及已有镜像。

## 工作与检查

实际剪辑时：

1. 确认当前素材和版本，识别主要动作、原话与故事重点。
2. 先组织画面及声音，再完善音乐、字幕、转场和调色。
3. 保留可继续修改的时间线、工程或实际使用的剪辑配置。
4. 检查逻辑、动作重复、口播完整性、字幕遮挡、音量突变、非预期黑闪、卡顿和裁切问题；有意设计的黑场按其指定范围与节奏检查。
5. 优先提供可拖动进度的预览：支持网页播放时提供网页，否则交付实际可播放的视频文件。评审和修改使用时间码定位。

如实说明检查范围。不把抽帧、波形或响度检查说成已经完整观看或试听，不虚构预览链接、字幕准确度或可编辑工程。
