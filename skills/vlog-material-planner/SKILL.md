# 分析与素材策划

对应现有素材策划岗；不承担独立审片或长期风格整理。

## 增量观察

先读本期目标、最新用户纠正、编号顺序及源观察索引。源路径、大小、修改时间未变且观察覆盖当前问题时复用；有替换疑点再核哈希。只补看新增、变更或尚不确定的素材/区间。源观察按源时间保存，与成片位置分开；成片移动不使原观察失效，但改裁切、速度或转场需复核相应技术问题。

动作、构图和方向以实际观察为依据，文件名只作定位。保留用户规定的组内数字顺序，按数值处理，服从最新重命名与组序纠正；缺片、重名、冲突明确标出，不拿别组相似名称替代。

## 可直接执行的简报

围绕主线、节奏和取舍给出版本化简报；每个候选镜头至少交清：

| 项目 | 交接内容 |
| --- | --- |
| 源与范围 | 文件路径/签名、帧率与方向元数据、源入出时间或帧、端点约定；变速时区分源时长与目标时长 |
| 动作与画面 | 正向/旋转或裁切关注点、速度、每角度完整动作次数、候选峰值和结果节点 |
| 连接与声音 | 转场意图、真实接触/动作声的候选位置、希望的音乐能量；未试听不得断言声音有效 |
| 证据与状态 | 缩略图/抽帧路径及源时间，实际观看/试听范围，用户已定项、建议项和待核项 |

有证据才精确定段；观察不足时交明确候选区间与待核原因，不造时间码，也不为补齐表格预做另一套主工程。优先有效构图、完整起落和指定结果；次数、节拍及是否变速按本期要求，不循环同一次动作充数。照片、视频静帧和动态镜头标清来源。

## 交接边界

Terra复用上述观察，仅定点确认最终切点、缺失/矛盾信息及转场、裁切、速度的技术边界，再检查实际成品。发现证据缺项时补相应段，不重启整库分析。

本岗给叙事、候选与转场意图；具体音乐由BGM设计，唯一主时间线与最终画声由Terra执行。明确局部反馈直接Terra，不重新启动策划。长期偏好候选连同证据交Astra，不自行更新技能。

内容审美按需读可用的$vlog-style；转场算法与运行时交$video-transitions、$video-use处理，不在简报里复制实现手册。
