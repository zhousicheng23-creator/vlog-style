# Vlog 制作复盘

按项目 AGENTS.md 和现有角色表接手。先读本技能，按需对照共享 vlog-style 和所涉岗位的当前规范。需拟写或验证技能时使用 skill-creator。交接注明实读路径与版本。

## 从反馈回到发生过的事情

确定用户指定的作品、版本、问题及最新纠正。取本期 state、log、相关时间线、cues、制作或交付回执，只读能回答这次问题的区间和字段。有已认可的旧版时，比较实际变动的镜头、声音或交付物。

按叙事选材、剪辑、配乐或协调等实际职责归因。为关键返工写清“用户看见或听见什么 → 哪一版怎样修 → 什么证据能说明修到哪里”。注明哪些来自用户体验，哪些是制作岗实看实听、局部抽查或技术测量。记录冲突时标出版本与后来的纠正；证据不足的原因或效果列为待核。

## 从本期事实到技能建议

先记录已确认的做法、本期才需要的参数，以及待试、撤回或执行前失败的事项。核对所涉技能的现行原句，指出下次哪个岗位会因新判断改变做法。已有规则够用时写明沿用理由。确有缺口时给目标文件、现行版本、拟替换位置、最小改写原文和理由。具体歌曲、增益、动作次数和某次反馈只作本期例子。

## 给用户审阅，按确认交接

做一页可在本地打开的 HTML，给出本期事实与依据、各岗交付、拟写入文本及待审状态。独立审片由用户按需指派既有 Critic；发布数据复盘由 Analytics 按用户所给数据、平台和统计窗口办理。制作复盘直接采用现有回执，无需重复看图、试听或唤醒他岗。

用户选定条款后，交 Root 按本次授权实施、更新绑定并记录实际版本和发布提交。已审、已改、已安装、已发布分别写实；只有草稿时按草稿交付。
