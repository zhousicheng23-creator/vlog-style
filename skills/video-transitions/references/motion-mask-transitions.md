# 动作引导蒙版转场

用于翻书、合电脑、推门、人物经过、手或衣服遮挡等动作连接场景。目标是让下一幕自然出现，并保留可辨认的动作和真实声音；不是每次场景切换都增加蒙版。

## 选择与边界

- 先实际查看两段素材，识别动作起点、遮挡边缘、运动方向和下一幕可接续的位置。
- 边缘不清楚、遮挡不足或镜头关系不合适时，优先动作匹配、运动衔接或直接切。普通走路不自动等于遮挡转场。
- 通常先尝试约一秒内完成；时长与速度根据真实动作和用户要求调整。精确跟随时不统一套匀速或缓动。
- 物体只覆盖局部时，要判断是否能闭合揭示区域。需要全屏延伸时明确这是顺着动作设计的近似擦除，不冒充真实遮挡。
- 不承诺任意素材自动获得同等效果；自动跟踪或分割仅在确实可用且经过检查时采用。

## 蒙版制作

1. **固定画面坐标与时间。** 先确定旋转、裁切、缩放、稳定处理和速度，再在最终画面及输出时间线上定位蒙版。后续更改这些操作，需要重新检查关键帧。
2. **安排叠层。** 原场景 A 在上，新场景 B 在下，转场区间重叠播放。本参考约定蒙版白色保留 A、黑色显示 B、灰色混合。不同编辑器检查其实际约定。
3. **选择边缘和起点。** 通常从真实动作刚开始的帧启动。检查揭示方向，使遮挡物经过的区域逐步变为 B，不等动作做完才突然擦除。
4. **选择形状。** 较直的书页、屏幕、门框用线性蒙版；弯曲或不规则轮廓用多边形、曲线或经过检查的分割结果。只抠出人物并不能表达人物经过后整侧画面的替换；揭示区域须正确延伸并闭合到画面边缘。
5. **检查保留侧。** 用中间一帧确认哪侧是 A、哪侧是 B；相反时才反转，不机械套用“必须反转”。
6. **打关键帧。** 先标开始、中途、结束的位置、角度或轮廓；逐帧补查，快速转动、弯曲、遮挡变化处加密。关键帧插值需要贴合动作，不固定平滑曲线。角度跨越 360 度时明确实际转动方向。
7. **调羽化。** 从小值开始，按边缘清晰度与画幅调节。羽化不能修复跟踪偏差，不能代替运动模糊；避免宽灰带造成两幕重影。不同软件的 25、30 等数值不可直接换算为通用标准。
8. **检查两端与接续。** 起点不提前露底，终点不留下 A 的细条。B 在重叠期间已经播放；结束后按其已推进的源时间继续，不重新从 B 的入点播放，也不漏帧。

| 真实动作 | 观察与处理重点 |
| --- | --- |
| 翻书 | 书页的角度、弯曲和翻动方向；手指是否需要保留在遮挡前景 |
| 合电脑 | 屏幕边缘的位置、角度变化和合盖时机；不是自动替换屏幕内容 |
| 人物经过 | 人物轮廓及经过后要替换的区域，必要时将前景人物独立保留 |
| 推门、穿门框 | 门板或门框边缘，下一幕进入时的位置与运动方向 |
| 手、衣服靠近 | 遮挡范围扩大及离开过程，注意失焦和运动模糊 |
| 普通走路 | 没有可靠遮挡时对齐步伐、方向或镜头运动，不硬加蒙版 |

## 原声、音乐与时间映射

- 每个片段记录源入点、源出点、输出起点及速度。固定速度 r 时：输出时刻 = 输出起点 +（源时刻 − 源入点）/ r。变速段分别记录或积分映射，不能简单把原时长加到下一幕起点。
- 画面和对应原声使用相同映射；保留自然摩擦和收尾，不能只拖长声音而制造可见动作的错位。保音高变速后也要核对实际瞬态。
- 环境声可适度提前或延后形成声音衔接；插销、上片、关门等明确接触声要对准实际接触。避免混入源片中不对应当前动作的下一声。
- 边界做短音量过渡以避免爆点，保留应有的动作攻击声。不要用过长淡入吃掉插销的“咔嗒”。
- 音乐按本期要求衔接、让位，不固定曲目或入口，不把混在现场录音中的声音声称为已分离的纯音效。
- 导出后检查实际音频时间，不能只相信滤镜参数。若延迟滤镜或时间戳行为异常，可用明确时长的静音段与原声拼接并重建时间戳，再验证；不把本次故障推断成所有版本都不可使用某个滤镜。

## 执行工具与记录

本 skill 不依赖固定剪辑软件。使用所在项目的执行工具；只有项目提供 video-use 时才按其技能与项目入口调用上游 helper（如 `python video_use.py <helper> ...`），FFmpeg 使用项目提供的路径，不假定全局 PATH。独立辅助脚本用具备所需依赖的 Python 运行。

- [build_motion_mask.py](../scripts/build_motion_mask.py)：根据手工关键帧生成灰度 PNG 蒙版序列，不自动检测、分割或跟踪物体。具体参数见 `--help` 和[示例配置](motion-mask-example.json)。它只制作蒙版，画面合成和混音仍由执行工具完成。
- [check_audio_sync.py](../scripts/check_audio_sync.py)：比较指定源区间与导出区间的原声，辅助估计延迟。先看 `--help`；低相关性或静音应标为无法判断，不作为通过。它不能单独证明画面与声音同步。
- 蒙版工具当前支持一个直线半平面或简单闭合多边形，不支持孔洞、复合区域或贝塞尔曲线；复杂轮廓需使用合适的编辑器或其他工具。PNG 序列不携带可靠的播放帧率，导入合成时显式设置。修改总帧数时同步修改关键帧位置，工具不自动重排。
- 音频工具对一个固定速度区间估计偏移，正值代表导出原声较预期更晚。保音高处理的算法和通道布局要与实际剪辑一致；`--tempo-layout` 默认为 stereo，可选 mono。不同处理链导致低相关时应报告无法判断，不为了获得“通过”而放宽门槛。工具拒绝覆盖已有报告。
- 脚本依赖：蒙版工具使用 NumPy、Pillow；声音工具使用 NumPy、SciPy 和显式传入的 FFmpeg。环境不满足时说明缺项，不暗中上传素材到云服务。
- 合成时保证蒙版、A、B 的尺寸、像素比例、帧率、起始时间及帧数一致。按蒙版白保留 A 的约定，输出为 `A × M + B × (1 − M)`；先抽查中间帧确定没有反向，再完整渲染。
- 保存素材映射、图层顺序、关键帧、羽化、速度、原声与音乐时间线、输出规格及实际执行配置。避免将某一次素材名、路径、旋转角、色彩值或音乐位置固化为默认。

## 验收与交付

1. 逐帧或慢放检查边缘、手和人物是否被误切、重影、露底及起止帧残留。
2. 正常速度检查动作完整性、场景关系、节奏和 B 的连续性；快放或逐帧结果不能代替正常速度观看。
3. 核对接触动作帧和对应声音，检查原声收尾、音乐衔接及音量。音频相关性仅用于辅助定位，低相关性、背景音乐覆盖或变速失真时不能据此下结论。
4. 检查导出尺寸、方向、帧率、时长、黑闪、解码错误及卡顿；如实说明实际完成的检查，不把波形检查描述成试听。
5. 新效果通常先生成带前后场景的局部预览缓存，按项目约定提供可播放预览；用户已授权整片时按范围执行，不额外要求逐步确认。提供网页时验证播放及进度拖动；不依赖永久有效的 localhost 链接作为唯一交付。
6. 保留全部原媒体、可修改配置和本次输出。工作文件及用户交付位置遵守项目约定；例如约定缓存在 `edit/`、交付在 `outputs/` 时按其执行，正式导出需符合当次授权。
