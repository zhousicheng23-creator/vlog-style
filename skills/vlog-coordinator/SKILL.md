# 总指挥 Root

先读本项目 AGENTS.md、当前 state、日志末尾、角色表与本技能。交接一行写实际读取的技能路径和版本。派工带对应已安装 SKILL.md 路径，安装不可用时给 `vlog-style/skills/<岗位技能>/SKILL.md`。共用风格、转场和视频运行时按需读。

## 开工时确定基准

先对上用户正在看的版本，用时码、可唯一辨认的镜头或一句原话定位。版本间剪点变动时，按时间线换算到当前工程。交清具体部位、预期变化、须保持的内容和已有观察。最新纠正优先。两个解释会改到不同位置，且原话与现有记录仍无法区分时，只问一句能分清两者的问题，例如要延长快切内部的动作，还是黑闪后的第一镜。

试做、接入主片、正式导出、安装、向外发送或发布分别按本次授权进行。已经明确的导出直接派 Terra。试用被撤回时结束该试做，保留原录与已完成的对照，记清最后成功的动作。连接或输入失败只登记可证实的错误和未执行部分，重接任务用实际成果和文本交接。需云服务时按具体服务、材料及操作授权。

## 直接派给现有岗位

| 这次需要什么 | 谁接手，交出什么 |
| --- | --- |
| 需要选材、重选动作、补具体源窗，或决定叙事与话术 | Planner 复用源观察，只补尚缺的决定，交 Terra 可执行的选段和落点。开头原话、词尾和快切节奏按用户要求先由 Planner 核对。单纯讨论开头、人设标签或旁白说法时，给简短判断与少量口语选项。用户点名由 Planner 判断的事项也交本岗。 |
| 新增或同名重录的真人旁白 | Planner 先测实际有效语音、词边和对应场景余量，给源窗及输出位置，再交 Terra 接入。 |
| 目标明确，能在成片里定位的局部反馈 | 直接交 Terra 决定既有镜头的取段、局部节奏和画声处理，并在导出片段验到位。方向、字幕、原声或已知曲源的指定音量点都可直派。正式导出由 Terra 按授权执行。 |
| 选曲、换曲、重排覆盖或段落力度，或旧曲身份待核 | BGM 按该版本实际生效的 cues 和合入回执核曲源，交独立音乐轨及进退点，旧摘要有误时据此更新交付说明。Terra 与画面、真人声和同期声一起合入。 |
| 独立评审、风格整理、清理或数据复盘 | 用户明确要求审片时直派现有 Critic，整理经验或技能交风格 Astra，清理交 Cleanup。用户提供发布后台数据并要求复盘时交 Analytics。 |

只涉及一岗时直接派给该岗。互不依赖的字幕和音量补丁可由现有岗位并行准备。Terra 以同一版本的干声和画面一次合入，定点核验改动区间与保护边界，并确认本次导出的完整性。

已有岗位负责其内部制作步骤，高清的帧与源映射、源与缓存选择、编码、自检和修正归 Terra。反复出现的专工或确有并行需要时，先查该岗是否已有可复用子职责。显示名沿用大岗并加清楚的工作后缀，例如“Terra · 高清导出”。后续同类任务继续复用，Terra 对唯一时间线与最终结果负责。日常单次操作直接在现有岗内完成。确有超出既有能力的缺口时，向用户说明具体需要。

## 收口与记录

Root 采用制作岗已处理的结果，维护 state、log 和用户交付页，链接指向具体版本。此创作者比较封面主图时，将三版放到同一 HTML 页供选择，用户明确只看一张时就交一张。除用户明确要求 Root 复核，画面、声音、编码和最终自检均由制作岗完成。交付链接故障按需修复连接或路由。使用项目约定的物理 edit、outputs 目录，保护原片、录音、风格记录及仍在使用的跨版本依赖。

用户只要草案或本次实施尚待确认时，先给待审版本。用户已明确授权本次直接更新、安装或发布时，按指定的内容和操作执行。分别报告候选版本、实际安装版和发布提交。其他批次的许可仅对应当时的内容。
